# 核对、验收与恢复

## 全量记录

记录以真实源范围为准，而非“运行了多少次操作”。从原版到第一版计算删除；从前一版到新版计算新增删除。多次操作落在同一连续删除区间可合为一个编号，但必须说明其全部内容与处理，不丢掉中间的停顿调整。

每条记录至少包含：稳定用户编号（例如 C001／R001）、源资产身份、原音轨起止秒（保留毫秒）、删除时长、删除原话、前后完整语境、类型与理由、前后保留停顿、fade／crossfade 参数、原版及新版试听位置。另列恢复的源范围及不足一帧的边界变化。用户编号不是内部 `[sN]` 或 clip ID，反馈时使用编号与原话。

自动转录引文标明识别局限。源摘录常包含剪口附近未删的词；不能全部当作删除原话。按词级覆盖范围提取，引文只占部分词时说明碎片／用时间范围试听。通过缩小范围抓出的片段文本不完整时，补查足够的上下文。

保留 JSON 作为恢复依据，CSV／Markdown 供核对。建议 JSON 结构：

```json
{
  "version": "本次版本",
  "projectId": "实时取得",
  "timelineId": "最终版",
  "baselineTimelineId": "比较版",
  "fps": 30,
  "cuts": [{
    "id": "R001", "assetId": "本次源资产",
    "sourceStartSeconds": 12.3, "sourceEndSeconds": 12.8,
    "quote": "自动转录的被删原话", "context": "足够判断语义的前后原话",
    "reason": "删除依据", "baselineAtSeconds": 12.3, "editedAtSeconds": 12.3,
    "adjustment": "实际保留停顿与接缝参数"
  }],
  "restorations": [], "boundaryAlignments": []
}
```

这里的秒数只是格式示例；不能套用到实际素材。恢复依据同时保存最终快照及修改意图，精确范围用整数帧／源微秒，避免反复浮点舍入。源范围和 timeline 坐标不能混用。

## 时间线审计辅助

将完整 `preview_timeline` 结果保存为 `{"state": ..., "entries": [...]}`，或保留 `{"state": ..., "timeline":{"entries": [...]}}` 结构。单条主对话轨、单个源资产、无变速／重排的任务可运行：

```sh
python3 scripts/audit_timeline.py --baseline baseline.json --edited final.json --track A1 --out audit.json
python3 -m unittest discover -s tests -p 'test_*.py'
```

脚本以源微秒计算差集，输出所有新增删除和多保留范围、两版试听位置，检查帧连续、单源顺序及原速。多源需单独按资产／实例处理；有转场或效果时默认拒绝，可显式加 `--ranges-only` 仅比较基础片段源范围，输出会记录忽略数量。此时还要独立验证合成状态，不能拿源范围差集证明实际混音或转场等效。

辅助结果需由 Agent 补入原话、语义理由、停顿、过渡与稳定编号，才成为用户记录。修改版本后旧编号按原源范围保留映射，避免重新排序使用户此前的 R001 指向别处。运行此脚本不产生剪辑、不调用 ChatCut、不上传素材。

## 对比试听页

同页保留原音轨、上一版和新版播放器，以及可筛选、按编号／原话查找的记录。每条记录可以从剪口前约3秒开始听到后约4秒；删除长段时原版播放到该段结束后，新版播放接缝。时间以本轮最终快照重新计算。大量记录分页，避免一页几百行影响核对；正常音频时长与网络 Range 请求要可用。

需要波形时展示原音轨能量概览与删除区间，支持点击定位。波形只证明能量变化，不能证明语义该删。先验证三条音轨的时长、无加载错误、一个代表性编号的定位播放；保留审阅页和工程界面截图。交付本机页面时链接旁的音频文件一并保留，若使用本地服务器就保持服务供核对。

## 必要验收

- 回读保留语句与预期逐条对照，保留否定、程度、归因、限定和逻辑连接；碎片残留、自动清理误删或顺序变化须修正。
- 检查整条主轨的帧范围，无意外空洞、叠音、重排或变速；允许的源边界变化逐处记录。多轨音频核查只有预期声音参与混音。
- 导出音频完整解码，实际长度与最终 timeline 帧数／fps 一致到合理编码余量，检测削顶与非有限值。MP3 可能包含编码延迟／padding，不靠容器时长单独证明源范围准确。
- 所有接缝有适当平滑；按帧映射检查短词剪口、低能量区及高风险接缝。自动数值检查可以发现突变，但不能证明听感绝对无爆音；条件允许抽听代表性片段，整期听审只有实际完成才能声称。
- MP3、JSON 与核对页使用同一最终版本；每次修剪更新成品和试听时间，不能拿未修正的初稿交付。

完成后保留原始媒体、可编辑版本、记录和成品。清理只覆盖本任务白名单中可再生成且不被活跃进程使用的临时文件；不删用户素材或素材库仍依赖的唯一源。停止本任务防休眠进程，保留仍服务审阅页的进程。

## 按用户反馈恢复

“恢复 R025”先在对应版本的记录中找到源资产与准确范围，再回读当前工程；若用户手动改动过，先合并其意图。复制当前版为新修订版，把同一个源位置放回原顺序，不恢复同一句在别处的重复实例。同步恢复被连带删掉的原有停顿，取消／重做原接缝的淡化或交叉渐变，避免恢复后重叠或断音。

局部恢复后核验前后语义、两侧接缝、实际新增时长和受影响试听位置，更新同编号状态及修订说明，导出新音频。只回退用户指出的范围，不整期撤销已经认可的剪辑。
