# 保守剪辑与静态文字规范

## 原话、重复和停顿

- 保持原有顺序、逻辑、立场、语气和信息。不自行补开头、口号、总结或调整论证顺序。
- 重念保留最完整自然的一遍，不机械保留最后一遍。前一遍独有的铺垫、主语、条件、转折、数字、单位、否定和结论不能丢。
- 不跨重念拼接两个未完成片段构造新句；保留有意义的重复强调。“然后”“所以”“但是”按语义判断，不用词表全删。
- 波形低能量只用于找候选。轻声词、句尾和呼吸也可能低于阈值；先找完整词边界，再听接缝。
- 明显卡壳和读稿长停顿可压缩；保留自然句间呼吸、话题切换和重点停顿。二次细剪不以统一毫秒门槛批删，不追求连珠炮。
- 每处拟剪范围检查前后约 0.5–1 秒，必要时扩展到完整上下句。先保留边缘余量，再按真实听感微调，不机械减去固定 padding。
- 不确定是否影响表达时保留，记录原因。缩短后的话应能自然朗读，不能说到一半被剪掉。

## 抬头看稿

先确认平视与看稿方向，用连续帧定位动作，并和转写、音频对应。

| 情况 | 处理 |
|---|---|
| 停止讲话后抬头找稿，再开始 | 压缩无声找稿部分，保护下一词起音 |
| 抬头时连续说有效信息 | 保留内容，不能因视线方向删词 |
| 抬头同时重念 | 比较完整尝试后选择保留哪一遍 |
| 眨眼、自然抬眼或无法确定 | 保留，不标成看稿 |

静音检测不能代替视线识别；单张图片不能确认一整段动作起止。

## 速度和中间过程

默认目标 1.1 倍，保持音高。记录源时间、剪后时间、最终时间、帧率及速度映射，使用帧或有理数避免累计误差。已经加速的素材和工程不能重复加速。

用户手剪是新基线，后续细剪只处理当前仍在的内容。固定剪辑与速度后再做字幕；继续删片段则旧 SRT 失效。

逐处记录：原片范围、原话/候选类型、删或留的理由、保留的完整表达、最终接缝位置、检查结果。对用户解释内容，不用卡片 ID 或索引代替原话。

## 字幕文字与静态呈现

- 中文每段以 4–7 字为起点，**完整语义优先**。“来介绍一下我自己”不能硬截成“来介绍一下我”，问候语不能漏首字。
- 一行是每种语言各一行：中文上行、英文对应下行；中文不拆两行，也不把中英文挤在同一横行。
- 超宽先按完整短语重新分段并对齐时间，或忠实精简英文；不因局部长句改大全片字号。先解决分段，再考虑必要的小幅局部适配。
- 全部字幕不带标点，且不改变含义。“1.1 倍”不能机械变成“11 倍”，可写“一点一倍”；英文用完整表达避免撇号。行业枚举通过空格或语义分段区分，不误成一个行业。
- 英文先理解上下文，再逐段对应口播；不补不存在的信息。每张需要翻译的卡片都有英文；姓名、数字、单位、否定词和专有名词逐项核对。
- 默认中文 Noto Serif SC / 思源宋体；英文 Josefin Slab 等已验证可用的衬线字体。沿用已确认的尺寸与位置。
- 1080×1920 竖屏历史基准为中文约 64 px、英文约 48 px，仅作起点，跨分辨率按比例调整。字幕位于颈部附近、居中稍下，避开嘴部，不贴底。
- 白色文字，纯黑阴影，无描边。阴影以较紧的黑色短偏移为主，可加少量软阴影；不要使用绿色阴影、光晕或大范围模糊。
- 优先原生字幕/文本，所有字静态；不添加打字机、缩放、弹跳、逐字高亮和配套音效。不用图片或动画承载整段字幕。

## 顶部标题

- 两行，浅黄色，比普通字幕稍大，阿里妈妈东方大楷，纯黑较重阴影，无描边。
- 位于顶部安全区，避开头部，从首帧到尾帧持续出现，不加动画。
- 优先使用用户给的标题；否则从原片主题拟定并说明采用文字，不把上一条视频标题固化到所有视频。
- 招聘服务主题示例：“完整介绍一下” / “我们的招聘服务”。仅同主题时使用。
- 验证字体在渲染端真实生效。本机安装或 API 字体值不证明成片字体正确；缺字/回退先查映射，无法提供时说明替代字体。
- 如平台只能用透明静态图承载标题，保留标题文案和版式源文件，按足够分辨率制作，明确其静态资产性质；不把整片或口播字幕压平。
