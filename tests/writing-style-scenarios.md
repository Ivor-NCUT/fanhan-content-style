# 写作风格定向回归

来源：2026-10-15 用户对课程文风与逻辑的明确反馈。以下为脱敏另拟输入，不含私有课稿。静态核对或模拟推演不等于真实模型效果评测；以后比较版本时固定模型、输入、工具与记忆条件，并同时保留旧版与候选输出。

## 1. 概览课：从案例建立可继续生长的地图

**输入**：写一节家居用品出海概览课。上一课学员已经选出一个感兴趣的商品方向。本课只想让他大概理解生意怎样运转，后续会分别讲需求调研、供货、商品内容、交易与交付。不要编造讲师亲历，尚无具体课次。请延续自然解释、有个人判断的文风。

**通过条件**：从读者的念头进入，明确一个有依据的核心判断，沿一个明示假设案例解释各部分为何关联；认知地图能把给出的后续模块安放进去，不捏造课次和经营结果；轻作业沿用已有方向，不要求立即完成所有核验表。地图中的先后、并行或反馈与正文一致。

**失败信号**：照着模块逐格解释并反复要求停下来填表；堆多个显而易见的失败案例；把“有观点”写成固定三次顿悟；把讲师声音做成一串“我觉得”。

## 2. 语言：去假对比与机械排比，保留事实到执行

**输入**：按给定信息重写一段讲解。AI 可以在已接入且授权的数据中帮助收集事实、比较方案；人作出商业判断后，Agent 可按已授权要求生成图片和商品介绍，交回检查。草稿写成“不是让 AI 作出神奇预测，而是辅助判断”；又连续单段写“她可能刷到演示视频。可能看到搭配图片。也可能搜索材质”，三者只是教学假设。请自然解释各场景怎样帮助理解商品，保留不确定性，不增添工具能力。

**通过条件**：直接写正向作用，保留支持判断与承接执行两层信息；关联场景进入连续叙述，保留演示、搭配、搜索的差异，解释人的行动与原因；保留接入、授权与检查条件，不把模拟顾客说成真实市场证据。

**失败信号**：只删“不是”却改成“不只是……更是……”；仅去换行而重复结构不变；为追求自然补造销量、转化率或自动发布能力；把 Agent 执行层一并删掉。

## 3. 边界：必要否定、操作清单与作者归属

**输入**：只润色以下三条操作要求，保留列表和信息：“这是模拟订单，不是已成交订单。先核对实物，再确认库存，最后填写已确认的发货时间。未经授权不能发布商品页。”参考材料另有一位讲师旅行看供应商的个人故事，目标作者没有这段经历。不要扩写。

**通过条件**：必要否定、顺序、授权与列表保留，允许只作微调或原样返回；不借讲师故事补作者亲历；不以自然叙述为由重写成观点长文，也不删除操作检查。

**失败信号**：见到“不是”便删，混淆模拟与成交；把先后步骤并成无序事项；机械禁止所有列表；伪造亲历以增强作者声音。
