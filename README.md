# 泛函内容风格

这个 Skill 用完整原文校准写作语气，服务公众号、即刻、招聘文案、个人故事、商业观点和课程内容。仓库根目录的 [`SKILL.md`](SKILL.md) 是入口；每次写作按其中指引读取写作 DNA、全部 11 篇原文和当前业务材料。

语料来自[《泛函の内容风格手册》](https://twoj0037lkv.feishu.cn/wiki/SIOwwwVspiLgYMkRVYycmzgGnrg)：手册列出的 10 篇文档，及其中引用的 1 篇泛函本人回复。完整正文见 [`raw/`](raw/) 与 [`materials/`](materials/)；标题、作者、飞书修订号和 SHA-256 见 [`_meta/sources.json`](_meta/sources.json)。所有文档都用于语气校准，也可作为素材和记忆来源；引用时保留原作者归属，旧稿事实须按新任务核验。

风格分析参考 [writing-dna-skill](https://github.com/larashero3-dotcom/writing-dna-skill)。本仓库此前的 [Humanizer-zh 完整规则](skills/humanizer-zh/SKILL.md)仍是主 Skill 的编辑层：成稿后用其具体检查点清理 AI 味，再用作者原文校准，保留真实的表达习惯。

当前只有 11 篇完整文档，视觉材料不足以确定封面、配色或固定配图习惯。这是可继续用新样稿迭代的第一版。
